# 🌊 Jal Protocol: DePIN Telemetry Engine (Hardware Simulator)

> **Note to Hackathon Judges:** 
> In a production environment, Jal Protocol utilizes physical IoT smart water meters (ESP32 microcontrollers paired with YF-S201 flow sensors). Because we cannot bring a pressurized municipal water pipe onto the presentation stage, this directory contains our **High-Frequency Hardware Telemetry Simulator**.

This simulator is designed to rigorously stress-test the **Monad blockchain's parallel EVM** by blasting cryptographically signed, real-time water consumption data to our smart contracts at scale.

---

## 🏗 System Architecture

The Jal DePIN stack separates the physical constraints of IoT from the blockchain using a Relayer architecture. 

1. **The Edge (Simulated here):** 50 concurrent smart meters read water flow, compile the data, and sign it using a secure hardware enclave.
2. **The Relayer (Node.js):** Receives the HTTP payload, verifies the cryptographic signature, and batches the transactions.
3. **The Settlement (Monad):** The `JalPool.sol` contract instantly updates the resident's water quota and mints `$JAL` tokens (compliant with the Gold Standard WBC framework).

## 📦 The Data Payload

Every ping generated by this simulator perfectly mimics the JSON payload structure of our production C++ firmware. It includes a simulated ECDSA hardware signature to prevent data-spoofing.

## 🚀 Quick Start Guide

To run the telemetry firehose locally and watch the data ingestion in real-time:

### 1. Install Dependencies
Navigate to this directory and install the required Node packages (axios for HTTP requests and chalk for terminal styling).

npm install

### 2. Environment Setup
Create a .env file in this directory to point the simulator to your local Relayer backend. 

# Default local relayer endpoint
RELAYER_URL=http://localhost:3000/api/telemetry

### 3. Ignite the Firehose
Run the engine. You will see a high-speed, light-red terminal output simulating 50 apartment units simultaneously transmitting water usage data.

node index.js

## 🛠 Hardware Bill of Materials (Production)
For anyone looking to manufacture the physical Jal Smart Meter, the open-source hardware stack requires:
* Microcontroller: ESP32-WROOM-32 (For Wi-Fi & ECDSA signing)
* Sensor: YF-S201 1/2" Hall-Effect Water Flow Sensor
* Enclosure: 3D Printed PETG (Files available in the /hardware/cad directory)
* Total Manufacturing Cost: ~$8.50 per unit at scale.
